# Materiales de «Estudiar con IA sin hacer trampa»

*Guía para padres: cómo ayudar a tu hijo de 10 a 18 años a aprender y recordar más con inteligencia artificial y técnicas de estudio basadas en la ciencia* — Leo Vallmar

Instrucciones listas para copiar, casos y plantillas del libro. Edición de **noviembre de 2026**: las funciones, menús y edades de las herramientas de IA se comprobaron entonces. Lo que cambie después se anota en [CAMBIOS.md](CAMBIOS.md).

## Cómo usarlo sin saber programar
- Para copiar una instrucción: abre el archivo, busca la instrucción y copia el bloque gris (botón de copiar a la derecha).
- Para descargarlo todo: botón verde **Code** → **Download ZIP**, y descomprime el archivo.
